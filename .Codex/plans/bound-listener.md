# Bound listeners, owned shutdown, supervised serve

Embedders cannot learn the port a service bound, cannot stop `serve()` without signalling their own process, and cannot learn that a listener stopped under them: the separate-port gRPC task's result is discarded and read only after HTTP ends, the exporter task is never observed, and a dead TLS handshake pump leaves `accept()` parked forever. Add `ActonService::bind() -> BoundService` (binds exporter, HTTP, gRPC; spawns nothing; drop closes the sockets) with `local_addr`/`grpc_local_addr`/`metrics_local_addr`, and make `serve()` equal `bind()` then `BoundService::serve()`. Add `ServiceBuilder::with_listener`, `with_metrics_listener` and `with_shutdown(future)`; the future is in addition to SIGINT/SIGTERM, and one already resolved when serve starts means nothing is accepted.

Run every serve path through one private supervisor: a cancellation token cancelled by a signal, the caller's future, or the first listener or watched task to end on its own; listeners in a `JoinSet` drain on it; the TLS pump (`TlsListener::stopped()`, fed by a watcher that ignores abort) and the exporter (`exited()`, a drop guard in its task) are watched. Any early exit or drain failure becomes one `Error::Internal` naming each. Exporter drains after the listeners and the agent runtime, as before. `Server::serve` uses the same supervisor.

Label failed handshakes with a bounded `kind` (plaintext, no_client_cert, bad_cert, timeout, eof, other) from the `rustls::Error` inside the io error, keep the WARN line and add the field, and count `tls.handshake_failures{kind}`. Test each kind with a real peer against a real mutual-TLS listener through the Prometheus handler, the pump watcher with injected panic and abort, the supervisor's early-exit, panic, watch and drain paths, and bind/serve/drop/early-shutdown end to end. Additive API plus a serve() behavior change: a minor release. This PR records its entries under `[Unreleased]`; the version bump, the release heading and the missing 0.43.0 and 0.43.1 entries land in the release PR.
